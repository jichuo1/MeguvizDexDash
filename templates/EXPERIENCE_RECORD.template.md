# EXP-NNN：问题与解决经验

- 关联任务/commit/build/profile/输入/平台：
- 结论状态：observed / hypothesized / reproduced / validated / superseded
- 更新时间与负责人：

## 1. 现象

描述可复现的外部行为、预期和实际差异、影响范围。性能问题注明完整工作量和计时窗口。

## 2. 证据

列出真实命令、日志、输入与二进制摘要、原始轮次、差分或崩溃记录。缺失证据明确说明。

## 3. 根因

把已验证机制与待验证假设分开。说明排除了什么以及使用了何种证据，避免凭相关性下结论。

## 4. 最终方案

给出实际改动、边界、版本与权衡；链接代码/ADR。仍为提议时明确写“未实现”。

## 5. 失败方案

记录尝试、失败现象、为何不能满足目标及可能适用的其他范围；不得捏造没有执行的尝试。

## 6. 验证范围

记录输入、平台、版本、独立 oracle、正确性、性能统计、资源与仍未覆盖场景。写清恢复/回滚方法和下一步。
